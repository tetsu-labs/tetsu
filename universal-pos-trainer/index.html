初回チュートリアル

Universal POS Trainer

1. POSを選ぶ

上部の切替から Airレジ / スマレジ / Square を選びます。POSごとに支払方法・画面名称・課題が変わります。

2. 基本会計を覚える

商品選択 → 数量・割引確認 → 支払い画面 → 支払方法 → 会計完了、という基本動線を反復します。

3. 実務シナリオで練習

返品、取消、個別会計、締め作業、現金過不足、領収書などをPOS別シナリオで練習できます。

4. 実機前の最終確認

このアプリは訓練用です。実店舗では店舗ルール、端末設定、決済会社の手順を優先してください。

利用規約・商標に関する表示

本アプリはPOS操作の学習・訓練を目的とする独立したシミュレーターです。 実在するPOSサービスの公式アプリ、公式教材、認定製品ではありません。

1. 利用目的

本アプリは、レジ業務の基本操作、会計フロー、返品・取消・締め作業などを模擬的に学習するためのものです。

2. 実店舗での利用

実店舗では、勤務先のマニュアル、責任者の指示、POS事業者・決済事業者が提供する最新手順を優先してください。本アプリの操作結果を実取引の保証として使用しないでください。

3. 商標

「Airレジ」「スマレジ」「Square」その他記載される製品名・サービス名は、それぞれの権利者の商標または登録商標である場合があります。本アプリは各権利者との提携・承認・後援関係を示すものではありません。

4. 画面・コンテンツ

本アプリは実在POSのロゴ、公式画面画像、公式アイコン等を複製せず、公開情報を参考に独自UIで業務フローを再構成しています。

5. 免責

実際のPOS仕様、料金、対応決済、画面構成、法令・税率等は変更される場合があります。公開前・業務利用前には必ず最新の公式情報を確認してください。

6. 学習データ

習熟度・履歴等はブラウザのLocalStorageに保存されます。端末やブラウザのデータ削除により消去される場合があります。
