# Universal POS Trainer

Airレジ・スマレジ・Squareを想定したPOS操作トレーニング用Webアプリです。

## Features
- 3種類のPOSモード切替
- POS別実務シナリオ 36課題
- 通常会計 / 割引 / 返品 / 取消 / 個別会計 / 複数支払い
- 開店・締め / 現金過不足 / 領収書 / バーコード
- 時間制レジラッシュ / 誤操作ドリル / 習熟度管理
- iPad Safari向けレスポンシブUI

## Run
`index.html` をブラウザで開くだけです。外部依存はありません。
