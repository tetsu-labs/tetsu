## 物語の基本設定
- 主人公：デューク東郷。異世界転生後も合理的な判断と戦闘技術を保持。
- 舞台：アリアハン、ロマリア、ダーマ神殿、ネクロゴンド、アレフガルド等。
- 職業：魔法使い → 僧侶 → 盗賊 → 賢者。
- 独自要素：魔法を計測・検証する研究、魔導狙撃銃、契約にもとづく魔王討伐。
- 主要人物：オルテガの娘である勇者、バラモス、ゾーマ、カンダタ、竜の女王。
